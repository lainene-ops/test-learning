# 工具使用手册

本机已配置的开发环境清单与日常用法。

## 一、JDK 21（Java 开发工具包）

**位置**：`C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot`

**环境变量**：`JAVA_HOME` 指向上面这个目录，`PATH` 里包含它的 `bin`。

它提供两个核心命令：

| 命令 | 作用 |
| --- | --- |
| `javac` | 编译，把 `.java` 源码变成 `.class` 字节码 |
| `java` | 运行 `.class` 字节码 |

流程：

```
Week1Hello.java  --javac-->  Week1Hello.class  --java-->  运行结果
```

**常用命令**

```powershell
java -version
javac -version

cd "C:\Users\Administrator\Documents\ChatGPT\New project\test-learning"
javac -encoding UTF-8 -d out code\Week1Hello.java
java -cp out Week1Hello
```

**参数含义**

- `-encoding UTF-8`：源文件是 UTF-8 编码，编译时按这个读
- `-d out`：编译结果放进 `out` 目录
- `-cp out`：classpath，告诉 java 去 `out` 里找类
- `Week1Hello`：类名，不是文件名，不带 `.class`

**注意**

- 类名必须和文件名完全一致，大小写敏感
- 运行时当前目录要能看到 `out`，否则报 `ClassNotFoundException`
- 不要手动改动 `Program Files` 里的文件

## 三、Git（版本控制）

**位置**：`C:\Program Files\Git`

**四个区域**

```
工作区（你编辑的文件）
  └─ git add ─→ 暂存区
                  └─ git commit ─→ 本地仓库
                                      └─ git push ─→ 远程仓库（GitHub）
```

**日常五条**

```powershell
git status                  # 看哪些文件改了
git add .                   # 全部放进暂存区
git commit -m "feat: 说明"   # 生成一次快照
git push                    # 上传到 GitHub
git pull                    # 拉取远程更新
```

**查看历史**

```powershell
git log --oneline
git diff                    # 看未暂存的改动
git show 提交号              # 看某次提交改了什么
```

**撤销操作**

```powershell
git restore 文件名           # 丢弃工作区改动（危险，改了就没了）
git restore --staged 文件名  # 从暂存区撤回
git reset --soft HEAD~1     # 撤销上一次提交，改动保留
```

**分支**

```powershell
git switch -c 新分支名       # 新建并切换
git switch main             # 切回 main
git branch                  # 查看分支
git merge 分支名             # 合并到当前分支
```

**提交信息前缀惯例**：`docs:` 文档、`feat:` 功能、`fix:` 修复、`chore:` 杂项。

**SSH 认证已配置**：推送不需要输入密码。

## 四、SSH 密钥（GitHub 免密推送）

**位置**：`C:\Users\Administrator\.ssh\`

- `id_ed25519`：私钥，**绝对不能外传**
- `id_ed25519.pub`：公钥，已登记到 GitHub
- `config`：让 `github.com` 自动走 `ssh.github.com:443`

**测试连接**

```powershell
ssh -T git@github.com
```

出现 `Hi lainene-ops! You've successfully authenticated` 即正常。

**换电脑时**

1. `ssh-keygen -t ed25519 -C "邮箱"`
2. 复制 `~/.ssh/id_ed25519.pub` 的内容
3. GitHub → Settings → SSH and GPG keys → New SSH key → 粘贴

## 八、报错对照表

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| `'java' 不是内部或外部命令` | 终端是装 JDK 之前开的 | 关掉重开，或重启 VS Code |
| `ClassNotFoundException` | 当前目录不对，或类名拼错 | `cd` 到项目根目录，检查类名 |
| `错误: 找不到符号` | 代码里有拼写错误或漏了分号 | 看报错行号，核对变量名 |
| 中文显示乱码 | 终端编码不是 UTF-8 | 删除 `-Dstdout.encoding=UTF-8`，让 Java 跟随终端 |
| `Permission denied (publickey)` | SSH 公钥没添加到 GitHub | 到 GitHub 设置里添加公钥 |
| `Failed to connect to github.com` | 网络阻断 | 用 SSH 443 通道（已配置） |
| `updates were rejected` | 远程有本地没有的提交 | `git pull --rebase` 后再 push |
