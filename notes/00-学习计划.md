# 12 周学习计划

每天：25 分钟看书/文档 + 60 分钟动手 + 5 分钟日志。
周六 3 小时（理论练习 1.5h + 代码 1.5h），周日 1.5 小时只复盘。

| 周次 | 主线内容 | 理论部分 |
| --- | --- | --- |
| 1 | Java 语法基础：变量、类型、字符串、分支、循环 | 测试定义、目的、七原则 |
| 2 | 数组、List/Map/Set、泛型、Stream 入门 | 测试分类：阶段、方法、类型 |
| 3 | 类与对象、封装、继承、接口 + 等价类边界值 | 等价类划分、边界值分析 |
| 4 | 异常、Files/NIO、Jackson JSON 读写 | 判定表、场景法 |
| 5 | Maven 工程结构、JUnit 5、断言、日志 | 状态迁移、正交实验、错误推测、探索式 |
| 6 | SQL 增删改查、聚合、多表 | 缺陷报告写法 |
| 7 | Linux 命令、日志、部署 | 缺陷生命周期、根因分析 |
| 8 | HTTP、网络基础 | 测试策略、风险排序、左移右移 |
| 9 | Git 进阶、架构常识 | 测试计划与测试报告 |
| 10 | 串联复习、接口检查脚本 | 综合演练与自测 |
| 11–12 | 期末周降速，每天 30 分钟 | 复习笔记、整理仓库 |

## 每周验收

| 周次 | 验收标准 |
| --- | --- |
| 1 | 仓库建好，三个小程序能跑 |
| 2 | 闭卷写出 5 个 List 操作和 5 个 Map 操作 |
| 3 | 能给一个输入框做出等价类与边界值用例表 |
| 4 | 能读懂判定表并补充遗漏组合 |
| 5 | 前 5 周代码整理成 3 个可独立运行的项目，并给工具类写 10 个 JUnit 单测 |
| 6 | 闭卷写 3 条多表查询 |
| 7 | 不看笔记敲 20 条 Linux 命令 |
| 8 | 闭卷画出一次登录请求的完整链路 |
| 9 | 仓库结构清晰，能独立走完 PR 流程 |
| 10 | 闭卷完成 10 道理论 + 5 道 SQL + 1 道用例设计 |

## 掉队处理

某天没完成不要顺延打乱整周节奏，记为「欠账」周六补 1 小时。
连续欠三天，砍掉当周非核心任务（通常是周六的代码练习），保住主线。
